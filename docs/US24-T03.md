Implementação: Bernardo, 25/11/2026. **Revisão por outra pessoa pendente.**
Frontend baseado em `0e3d632`; contrato da US24-T02 conferido no backend
`d4fd3aa`. A branch inclui US10-T02-FE, em commit anterior separado.

## Usar

Com o backend em execução, iniciar `python servidor.py` e abrir **Mapa de
indicadores** no menu (`http://127.0.0.1:5173/indicadores-mapa.html`).
O endereço da API segue `js/comum/config.mjs`. A tela é pública.

Escolher linha opcional, sentido, indicador, início e fim no horário de São
Paulo. **Buscar redes no período** consulta os indicadores publicados e permite
fixar uma versão GTFS. Não existe catálogo de redes específico neste contrato;
**Mais versões** percorre as páginas quando necessário. Nenhum UUID é inventado.

Alternar paradas, trechos, distritos ou subprefeituras. Para territórios, escolher
a base de paradas ou trechos. O código opcional restringe a API; a busca por
nome/código abaixo do mapa filtra a lista da página. **Localizar** destaca o
local e abre seu valor, motivo de ausência, período e conjunto.

Filtros, versões, faixas, página e janela selecionada ficam no endereço.
A consulta é refeita ao alterar filtros. Respostas canceladas não substituem
a seleção atual. Resultados de conjuntos/janelas diferentes ficam separados no
seletor; o mapa não calcula uma média entre revisões sobrepostas.

## Cor e procedência

O mapa usa as geometrias GeoJSON e os valores recebidos. Não calcula indicadores,
não reprojeta as coordenadas e não agrega percentuais no navegador. Trechos
mantêm sua geometria inteira, incluindo os que cruzam limites. As referências
de rede e limites territoriais ficam disponíveis em **Referência dos dados**.

Quatro tons de azul representam intervalos explícitos. Os três limites podem
ser ajustados; o valor do limite pertence à faixa seguinte. Percentuais começam
com 25/50/75; frequência com 2/4/8 passagens/h. As faixas são descritivas, sem
atribuir aprovação ou reprovação operacional. Unidade, janela exibida e fonte
acompanham a legenda. Zero recebe cor numérica; `null` usa cinza tracejado e o
motivo de ausência da API, tanto na tabela quanto no mapa.

O backend atual agrega territorialmente apenas percentuais com contagens
compatíveis. Frequência territorial retorna `AGREGACAO_NAO_SUPORTADA`, exibida
em cinza com orientação para consultar paradas/trechos. Sem indicadores, a API
pode devolver uma coleção vazia; a interface não inventa polígonos nem zeros.
Áreas sem dados devolvidas pela API permanecem localizáveis.

Leaflet 1.9.4 segue a versão e a integridade já usadas no projeto. A base visual
usa OpenStreetMap com atribuição. Falha ao carregar a biblioteca mantém os
valores e a legenda na lista e oferece nova tentativa. Erros HTTP não conservam
camadas antigas como se fossem resultado dos novos filtros. HTTP 429 respeita
o prazo informado antes de uma nova consulta.
