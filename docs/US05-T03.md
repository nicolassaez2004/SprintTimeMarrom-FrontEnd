# US05-T03 · Página do acervo oficial

A aba **Acervo oficial** de `index.html` consulta a API pública da US05-T02. Os filtros usam o
tipo e a data do documento, com limites inclusivos. A lista exibe título,
tipo, órgão e data e permite navegar pelas páginas do resultado.

## Como testar

1. No backend, com o ambiente Python configurado e a migração
   `us05_0014` aplicada à base de teste, inicie a aplicação com `python app.py`.
2. No frontend, rode `python servidor.py`.
3. Abra [Acervo oficial](http://127.0.0.1:5173/#acervo). Selecione
   Contrato ou Indicador oficial e um período que contenha documentos
   catalogados. Confira o órgão e a data e use **Abrir PDF original**.
4. Consulte um período sem documentos e use **Limpar filtros** para voltar à
   lista completa. Para abrir o PDF, a aplicação usa o ID do documento na
   rota que entrega o original registrado pelo backend.

A URL pública do backend fica no meta `api-base` de `index.html`.
O padrão do projeto é `http://127.0.0.1:5000/`.

## Evidência da verificação

| Cenário | Resultado |
| --- | --- |
| Contrato com início e fim em 01/03/2026 | A busca retornou somente o contrato dessa data, com o órgão correspondente. |
| Contrato em 02/03/2026 | A tela exibiu “Nenhum documento encontrado”. Limpar restaurou a lista. |
| PDF disponível | A API entregou o original e o visualizador abriu com opção de nova aba. |
| PDF removido da pasta temporária do ensaio | A API respondeu 503 e a tela mostrou o aviso junto ao documento. |
| Indicador com órgão em branco | O item ficou visível com “Órgão não informado” e a data correta. |

Os cenários acima foram executados no navegador com Flask, SQLite e arquivos
sintéticos locais. Os dados da Aiven ficaram fora do ensaio.

- Frontend: `node --test tests/*.test.mjs` passou com 15 testes, sendo 7 do acervo.
- Backend: `python -m pytest tests/documentos -q` passou com 41 testes.
